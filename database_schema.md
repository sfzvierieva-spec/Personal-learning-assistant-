# Database Documentation

## Overview

The Personalized Learning Platform uses an SQLite database named `learning_platform.db`.

The database stores all information required by the application, including:

- User profiles
- Uploaded courses
- AI-generated content
- User feedback

The database was designed to support personalized learning experiences and maintain relationships between users, educational resources, generated content, and feedback.

# Table Descriptions

## profiles

Stores user information and learning preferences.

| Field | Type | Description |
|---------|---------|---------|
| id | INTEGER | Primary key |
| username | TEXT | Username |
| email | TEXT | Unique email |
| learning_style | TEXT | Preferred learning style |
| created_at | TIMESTAMP | Creation date |

Examples of learning styles:

- Visual
- Auditory
- Reading/Writing
- Kinesthetic

---

## courses

Stores uploaded courses and learning resources.

| Field | Type | Description |
|---------|---------|---------|
| id | INTEGER | Primary key |
| profile_id | INTEGER | Related user |
| course_name | TEXT | Course title |
| file_path | TEXT | Location of uploaded file |
| upload_date | TIMESTAMP | Upload date |

Purpose:

- Manage uploaded files.
- Associate courses with users.
- Track uploaded learning resources.

---

## generations

Stores content generated by AI.

| Field | Type | Description |
|---------|---------|---------|
| id | INTEGER | Primary key |
| profile_id | INTEGER | Related user |
| course_id | INTEGER | Related course |
| prompt | TEXT | User request |
| generated_content | TEXT | AI output |
| generation_date | TIMESTAMP | Generation timestamp |

Examples:

- Course summaries
- Simplified explanations
- Quizzes
- Flashcards
- Study guides

---

## feedbacks

Stores user ratings and comments.

| Field | Type | Description |
|---------|---------|---------|
| id | INTEGER | Primary key |
| profile_id | INTEGER | Related user |
| generation_id | INTEGER | Related generation |
| rating | INTEGER | User score |
| comment | TEXT | User feedback |
| feedback_date | TIMESTAMP | Submission date |

Typical rating scale:

- 1 = Poor
- 2 = Fair
- 3 = Good
- 4 = Very Good
- 5 = Excellent

# Relationships

## User → Courses

One user can upload multiple courses.

```text
profiles (1) -----> (N) courses
```

---

## User → Generations

One user can create multiple AI generations.

```text
profiles (1) -----> (N) generations
```

---

## Course → Generations

One course can produce multiple generated outputs.

```text
courses (1) -----> (N) generations
```

---

## Generation → Feedback

One generated output can receive multiple feedback entries.

```text
generations (1) -----> (N) feedbacks
```

# Technology

Database engine:

- SQLite

Language used:

- Python (`sqlite3` library)

Advantages:

- Lightweight
- Easy deployment
- No additional server required
- Well suited for educational projects

---

# Database Creation

The database can be created by running:

```bash
python create_database.py
```

This script automatically creates all required tables if they do not already exist.

Generated file:

```text
learning_platform.db
```
